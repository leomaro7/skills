# 見た目を変える

テンプレートは**構造**と**テーマ**に分かれている。
`assets/template.html` の CSS のうち、`/* === THEME:START === */` から `/* === THEME:END === */` までがテーマで、色・書体・余白・角の丸み・強調の出し方を持つ。
それより上は寸法とレイアウトだけで、どのテーマでも共通。

**この分離があるので、内容を書いたあとでも見た目だけ差し替えられる。**
同じ台本のまま2つ作って見比べるのが、いちばん速い決め方。

```bash
python scripts/apply_theme.py --list                          # 一覧
python scripts/apply_theme.py slides.html --theme dark        # 差し替え
python scripts/apply_theme.py slides.html --theme corporate --accent "#0b6bcb"
```

差し替え前のファイルは `slides.html.bak` に残る。
差し替えたら撮り直す（`build_video.py ... --skip-narrate`）。

## 6つのテーマ

| テーマ | 地 | 見出しの書体 | 角 | 性格 |
|---|---|---|---|---|
| `plain` | 白 | ゴシック | やや丸 | 無印。どの組織の色でもない既定 |
| `editorial` | 生成り | **明朝** | ほぼ直角 | 読み物寄り。落ち着いた社内共有 |
| `dark` | 暗い | ゴシック | 丸 | デモ・エンジニア向け。コードが映える |
| `corporate` | 白 | ゴシック（詰まり気味） | 直角 | 社外向け・フォーマル。罫線で締める |
| `vivid` | 濃い色面 | ゴシック（極太・大） | 大きく丸 | ティザー・告知。情報量は少なく |
| `mono` | ほぼ白 | ゴシック（極太） | 直角 | 色を使わない。ブランド色が無い/使えないとき |

`dark` と `vivid` は地が暗いので、外部画像を取り込むときは `--pad-color` も揃える。

```bash
python scripts/build_video.py ... --pad-color "#15171b"    # dark
```

## テーマが持つ変数

テーマを自作・改変するときの一覧。
構造側はすべてこの変数経由で参照しているので、ここを変えれば全スライドに効く。

| 変数 | 役割 |
|---|---|
| `--bg` `--ink` `--muted` | 地・本文・補足 |
| `--accent` | 差し色。ラベル・箇条書き・強調・ステップ番号 |
| `--rule` `--rule-w` | 罫線の色と太さ |
| `--panel` `--panel-ink` | コード枠の地と文字 |
| `--font` `--font-head` `--mono` | 本文・見出し・等幅の書体 |
| `--h1` `--h2` `--statement` `--head-weight` | 見出しの大きさと太さ |
| `--pad-x` `--pad-y` `--tracking` | 余白と字間 |
| `--radius` `--flag-h` `--dot-radius` | 角の丸み、タイトル下の帯、箇条書きの点の形 |
| `--label-ls` `--label-tt` | ラベルの字間と大文字化 |

変数で足りない部分は、テーマ CSS の中で通常のセレクタを書けば上書きできる（テーマは構造より後ろに置かれる）。
`corporate` が見出しに下罫線を足し、`mono` が箇条書きの点を横線にしているのがその例。

## 新しいテーマを足す

`assets/themes/` に1ファイル増やすだけ。
1行目のコメントを `/* theme: 名前 — 説明 */` の形にしておくと、`apply_theme.py --list` に説明が出る。

```bash
cp assets/themes/plain.css assets/themes/ourbrand.css
# 変数を書き換えて
python scripts/apply_theme.py slides.html --theme ourbrand
```

組織のテーマを1つ作って置いておけば、以降の動画はすべて同じ見た目に揃う。

## ブランド色を1色だけ差し替える

いちばん手軽で、いちばん効く。
テーマはそのままに、差し色だけを組織やプロダクトの色に変える。

```bash
python scripts/apply_theme.py slides.html --theme corporate --accent "#0b6bcb"
```

ラベル・箇条書きの点・強調の下線・ステップ番号・タイトル下の帯がまとめて追従する。
手で `--accent` を書き換えると強調の下線だけ元の色が残りやすいので、このオプションを使うほうが安全。

**地の色は白のままにするか、ごく薄く落とすかで印象が変わる。**
動画は明るい面が長時間映り続けるので、純白（`#ffffff`）より少し落とした色のほうが見ていて疲れない。
`plain` は純白、`mono` と `editorial` は少し落としてある。

## 書体

`--font`（本文）と `--font-head`（見出し）はフォント名を順に試すリストで、macOS（ヒラギノ）と Windows（游ゴシック・メイリオ）の両方を含めてある。
`editorial` は `--font-head` だけ明朝にして、本文はゴシックのまま残している。
**見出しの書体を変えるのは、色を変えるより印象が動く。**
**片方の OS にしか無いフォントを先頭に置くと、もう一方の環境で別の見た目になる**ので、両 OS ぶんを並べておくこと。

Web フォントを使う場合は `<style>` の先頭に `@import` を置く。
撮影時にフォントの読み込みを待つので、表示が間に合わないことはない。
ただしネットワークが要るので、オフラインで作る可能性があるならローカルのフォントにしておく。

## ロゴを入れる

全スライドの隅に置くなら、`.slide` に対する擬似要素で一括指定するのが楽。
画像はデータ URI にするか、HTML と同じディレクトリに置いて相対パスで参照する。

```css
.slide::after {
  content: ""; position: absolute; left: 140px; bottom: 84px;
  width: 132px; height: 32px;
  background: url("logo.png") left center / contain no-repeat;
  opacity: 0.55;
}
.slide--title::after, .slide--closing::after { opacity: 1; }  /* 最初と最後は主張させる */
```

スライド番号（`.slide__num`）と位置がぶつかる場合は、番号側の `right` / `bottom` をずらす。

## 配置を変える

色と書体がテーマ、**配置はモディファイア**で、互いに直交している。
寄せ・分割比率・列数・画像の置き方は `references/layouts.md` にカタログがある。
テーマを変えても配置は変わらず、配置を変えてもテーマは効いたままになる。

## レイアウトを足す

既存の5種類（`slide--title` / `.points` / `slide--statement` / `.split` / `.steps`）で足りないときだけ足す。
構造側（THEME ブロックより上）に書き、色は必ず `var(--...)` 経由にする。
直に色を書くとテーマを差し替えても変わらない。
動画では**レイアウトの種類が多いほど画面が落ち着かなくなる**ので、1本の動画で使うのは3〜4種類までに抑えるとよい。

足すときは、既存のクラスと同じ余白・文字サイズの体系に乗せる。
見出しは `h2`（76px）、本文は 32〜40px、補足は 28〜32px。
この3段階から外れると、そのスライドだけ浮く。

## 解像度と比率

既定は 1920×1080（16:9）。
変えるときは `--width` / `--height` と、テンプレートの `.slide` の `width` / `height` を**両方**合わせる。
片方だけ変えると、撮影した画像が引き伸ばされる。

```bash
# 正方形（SNS向け）
python scripts/build_video.py ... --width 1080 --height 1080
```

縦長（9:16）にすると1枚に置ける情報が大きく減るので、箇条書きは2項目まで、見出しは1行に収める。

## 外部ツールで作ったスライドを使う

Canva・Keynote・PowerPoint・Figma・Google スライドで作ったものを、そのまま動画にできる。
デザインが既に確定している場合や、スライドは人が作って音声だけ載せたい場合に向く。

1. PNG または JPG で全スライドを書き出す（Canva なら「ダウンロード → PNG → すべてのページ」）
2. 1つのディレクトリにまとめる
3. `--frames` に渡す。
   `--slides` は不要

```bash
python scripts/build_video.py --frames ./canva-export --narration narration.json --outdir build
```

**ファイル名を台本の `id` と同じにしておくと確実。**
連番のままでも、枚数が台本と一致していれば名前順（`Slide 10` は `Slide 2` の後）で対応づけ、どの画像がどのスライドになったかを表示するので、そこで確認する。

解像度や比率が混ざっていても、はみ出さないよう縮めてから `--pad-color` で余白を埋める。
ただし**比率が混ざると再生中に絵の大きさが変わって落ち着かない**ので、書き出し前に揃えておくほうがよい。

この経路ではスライドの中身を読めないため、「スライドに文章を並べていないか」の確認はできない。
**外部ツールで作る場合こそ、スライドに文章を書きすぎていないかを自分で見る。**
判断基準は変わらない——その文字を、ナレーションと同時に読ませても大丈夫か。
