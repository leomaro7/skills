# 外部ソース許可リスト

[5] 外部検索で使う。**ここに載っているソースだけ**を提案対象にする。
利用者が随時増減してよい（このファイルが唯一の正）。

## 提案してよい（信頼できる一次ソース）

検索可能なレジストリを一次検索先に据え、平坦なリポジトリ列挙はその次に当たる。

| ソース | URL | 備考 |
|--------|-----|------|
| 公式 MCP レジストリ | https://registry.modelcontextprotocol.io | API で検索可能・**最優先** |
| Docker MCP Catalog | https://hub.docker.com/mcp | Docker Hub 上の検証済みカタログ |
| 公式 MCP サーバ集 | https://github.com/modelcontextprotocol/servers | キュレーション済みリスト |
| Anthropic 公式スキル例 | https://github.com/anthropics/skills | スキルの公式例 |
| 各ベンダー公式提供 | （提供元の公式リポジトリ） | MCP / スキルを提供元自身が出しているもの |

> スキルには MCP のような中央ハブが現状無い。スキルは Anthropic 公式例＋
> 各提供元の公式リポジトリを当たる（ハブ前提で探さない）。

## レビュー専用（自動提案しない・人間のレビュー候補として別枠で挙げる）

- コミュニティの awesome 系リスト
- サードパーティのディレクトリ（mcp.so / Smithery / Glama 等）

## 信頼性チェック（許可リスト内でも必須）

以下を満たさないものは提案しない：

- 提供元が明確で信頼できる（公式・著名な提供元・許可リスト掲載）
- メンテナンスされている（更新が止まっていない）
- 権限・データの扱いが妥当（過剰な権限を要求しない）

許可リスト外で有望なものは、**提案せず**に人間のレビュー候補として別枠で挙げる。
AI が信頼性を独断で判定して採用しない。
